# Приложение на Android для приготовления пищи из имеющихся продуктов

**Android App for Cooking with Available Products**

«Приложение на Android для приготовления пищи из имеющихся продуктов» - мобильное приложение для Android, которое предназначено для подбора рецептов на основе текущих продуктов пользователя. Основная цель проекта заключается в создании удобного инструмента, который помогает пользователю определиться с блюдами на основе имеющихся продуктов, учитывая аллергии пользователя, даёт пошаговый план приготовления выбранных рецептов, а также позволяет управлять списком покупок и отслеживать историю приготовления.

## Ссылка на APK файл

https://github.com/ifemochka/AppForCooking/releases/latest

## Основные функции

Данное мобильное приложение предоставляет возможность управлять инвентарём-холодильником с текущими продуктами пользователя (добавление, удаление, группировка по категориям). На основе содержимого инвентаря-холодильника, аллергий пользователя  и применяемых фильтров приложение предлагает рецепты, даёт пошаговый план приготовления выбранных рецептов, указывает наличие и отсутствие продуктов для рецептов, позволяет добавить недостающие ингредиенты в список покупок, а также позволяет отслеживать историю приготовления рецептов пользователя.


## Архитектура

Для приложения была использована клиент-серверная архитекутра.

### Клиентская часть 

Клиентская часть приложения написана на языке Kotlin с исопьзованием UI-фреймворка Jetpack Compose.

### Серверная часть 

Серверная часть приложения написала на Node.js с использованием фреймворка Express.js и СУБД SQLite.
